## Placeholders

各章の `<...>` は、チームのリーダーから聞く値か、自分で確かめる値に置き換える。ホスト名、ユーザー名、パーティション名、
ストレージのパスは環境ごとに違うため、この repo には書かない([CONTRIBUTING.md](../../CONTRIBUTING.md) の Rules)。

| placeholder | 中身 | 確かめ方 |
| --- | --- | --- |
| `<ログインノード>` | ログインノードのホスト名/IP アドレス | GMOクラウドのNavi |
| `<ユーザー名>` | クラスタのユーザー名 | GMOクラウドのNavi |
| `<ポート番号>` | ログインノードの SSH のポート | GMOクラウドのNavi |
| `<パーティション>` | 計算ノードのパーティション名 | `snodes` で確認([2 章](02_slurm.md)) |
| `<共用ストレージ>` | そのパーティションの計算ノードから見える、チームの共用ストレージ | 計算環境 |
| `<モデルのスナップショット>` | Qwen/Qwen3.8-27B の重みを置いたディレクトリ | チーム管理 |
| `<Molmo2-8B のスナップショット>` | allenai/Molmo2-8B の重みを置いたディレクトリ | 同上 |
| `<時間>` | ジョブの時間の上限(`--time`) | - |
| `<提出用リポジトリ>` | チームの org にある提出用の Hugging Face のリポジトリ(例: `team-alpha-org/capx-submission`) | チーム |
| `<team_id>` | 提出用リポジトリの登録に使った `team_id` | チーム |
| `<adapter のリポジトリ>` | チームの org に置く、学習した adapter の Hugging Face のリポジトリ(例: `team-alpha-org/qwen38-dmpo-adapter`) | - |

チームの約 20 名が同じ共用ストレージを使うため、各自の作業は `<共用ストレージ>/<ユーザー名>/` の下で行う
([3 章](03_clone.md))。

最初は [1. GMO クラウドへのログイン](01_login.md) から始める。
